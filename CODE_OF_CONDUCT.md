# Code of Conduct

Agent Deck welcomes contributions from people of all backgrounds and experience levels.

Expected behavior:

- Be respectful, specific, and constructive.
- Assume good intent while discussing technical disagreements.
- Keep project discussions focused on user safety, privacy, accessibility, and maintainability.
- Accept that a maintainer may request tests, documentation, or a smaller scope before merging.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, sexualized conduct, publishing private information, and intentional disruption of project infrastructure.

Report conduct concerns privately through GitHub repository contact or a repository maintainer. Do not include secrets or private runtime data in reports.
